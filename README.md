# SS14 MIDI Studio

Программа для подготовки MIDI-файлов к инструментам Space Station 14: проверяет, уложится ли файл в лимиты игры, чинит ошибки и при необходимости упрощает его. Есть пианоролл для ручной правки и прослушивание.

## Лимиты SS14

Сервер пропускает не больше 1000 MIDI-событий в секунду (`midi.max_events_per_second`), клиент отправляет не больше 60 за кадр (`midi.max_events_per_batch`). Если файл плотнее, у других игроков он начинает отставать, а потом инструмент останавливается.

## Возможности

- Проверка файла по лимитам и график нагрузки по всей песне.
- Починка: лишние note_off, наложения нот, незакрытые ноты, повреждённые дорожки (пропущенные байты, номера каналов больше 16, дорожки из одних беззвучных нот).
- Три режима обработки:
  - «Безопасный» - в перегруженных местах убирает наименее заметные ноты: дубли в унисон, очень короткие ноты, октавные удвоения, внутренние голоса, тихие удары. Мелодию и бас оставляет.
  - «Без потерь» - чинит файл, выравнивает громкость и убирает лишние служебные события. Ноты не удаляет, поэтому очень плотный файл может остаться перегруженным.
  - «Только починка» - исправляет ошибки файла, громкость и плотность не меняет.
- Выравнивание громкости: ударные не громче 85, мелодия нормализуется по всей песне.
- Пианоролл: выделение, перемещение, изменение длины, рисование, громкость, копирование, транспонирование, квантование, отмена. Ноты, убранные обработкой, показываются красными рамками, их можно вернуть.
- Каналы: смена инструмента, «без звука» и «соло» при прослушивании, скрытие, удаление.
- Прослушивание через системный MIDI-синтезатор. На Windows это `gm.dls`, тот же набор звуков, что у SS14. Можно сравнить результат с исходником и послушать с сетевыми лимитами игры.
- Обработка папок целиком, интерфейс на русском и английском.

## Как пользоваться

1. Запустите `SS14MidiStudio.exe` и перетащите в окно MIDI-файлы или папку.
2. Выберите режим и нажмите «Обработать».
3. Послушайте результат, при необходимости поправьте ноты и нажмите «Сохранить» (Ctrl+S).

Результат сохраняется рядом с исходным файлом с суффиксом `_ss14.mid` или в выбранной папке. Справка и горячие клавиши - F1.

## Консольная версия

```
ss14midi analyze <файлы или папки>
ss14midi fix <файлы или папки> [--preset safe|quality|repair] [--out <папка>] [--json]
```

Файлы можно перетащить прямо на `ss14midi.exe`, тогда они обработаются в режиме «Безопасный».

## Сборка

Нужен Rust (stable):

```
cargo build --release
```

Результат: `target/release/SS14MidiStudio.exe` и `target/release/ss14midi.exe`.

Тесты: `cargo test --workspace`. Чтобы прогнать обработку на своих файлах, укажите папки в переменной `SS14MIDI_CORPUS` через `;` и запустите `cargo test --release -p ss14midi-core --test corpus -- --nocapture`.

## Структура

- `crates/core` - чтение и запись MIDI, анализ, обработка.
- `crates/cli` - консольная версия.
- `crates/app` - приложение на egui.
