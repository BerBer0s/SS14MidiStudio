# SS14 MIDI Studio

Готовит MIDI-файлы для инструментов **Space Station 14** так, чтобы они гарантированно играли в игре: без «судорог пальцев», оглушения и остановки инструмента. Плюс пианоролл-редактор и прослушивание.

## Зачем

У инструментов SS14 жёсткие лимиты: **1000 MIDI-событий в секунду** и **60 за кадр** (`midi.max_events_per_second`, `midi.max_events_per_batch`). Перегруженный файл сначала «плывёт» у других игроков, а потом персонажа оглушает и инструмент останавливается. Многие файлы из интернета вдобавок битые: в них есть пустые note_off, наложения нот и зависшие ноты.

## Что умеет

- **Проверка.** Показывает, пройдёт ли файл лимиты. График плотности по всей песне, перегруженные места заштрихованы.
- **Починка.** Убирает пустые note_off, разбирает наложения одной ноты, закрывает зависшие ноты, восстанавливает битые файлы: сообщения с пропущенным байтом, дорожки с номером канала больше 16, дорожки из одних беззвучных нот.
- **Оптимизация** — три пресета:
  - **Безопасный** — гарантирует лимиты. В перегруженных местах убирает самые незаметные ноты по порядку: дубли в унисон, микроноты, октавные удвоения, внутренние голоса, тихие удары. Мелодию и бас не трогает никогда.
  - **Без потерь** — всё без потерь (повторы, служебные события, прореживание кривых), ноты не удаляются.
  - **Починка** — только исправление ошибок файла.
- **Громкость.** Ударные ограничиваются до 85. Мелодия нормализуется по всей песне сразу, поэтому баланс микса сохраняется.
- **Пианоролл.** Выделение, перемещение, растяжение, рисование, удаление, громкость, копирование, транспонирование, квантование, отмена и повтор. Убранные ограничителем ноты видны красными рамками, двойной клик возвращает их.
- **Каналы.** Смена инструмента, mute и solo при прослушивании, скрытие, удаление.
- **Прослушивание** через системный MIDI-синтезатор (на Windows это тот же набор `gm.dls`, что использует SS14). Можно переключаться «результат / исходник».
- **«Как слышат другие».** Эмуляция сетевых лимитов клиента SS14: слышно, как перегруженный файл отстаёт в игре.
- Пакетная обработка папок, интерфейс на русском и английском.

## Как пользоваться

1. Запусти `SS14MidiStudio.exe` и перетащи в окно MIDI-файлы или папку. У каждого файла появится оценка: «Пройдёт», «На грани» или «Не пройдёт».
2. Выбери режим обработки и нажми **«Обработать»**. Обработку можно отменить, как любую правку.
3. Послушай результат, сравни с исходником, при желании поправь ноты в пианоролле и нажми **«Сохранить»** (Ctrl+S).

Для многих файлов сразу — **«Обработать и сохранить все»** слева внизу. Результаты сохраняются рядом с исходниками с суффиксом `_ss14.mid` или в выбранной папке. Справка и горячие клавиши — по `F1`.

## Консольная версия

```
ss14midi analyze <файлы или папки>
ss14midi fix <файлы или папки> [--preset safe|quality|repair] [--out <папка>] [--json]
```

Можно просто перетащить файлы на `ss14midi.exe` — они обработаются пресетом «Безопасный».

## Сборка

Нужен Rust (stable).

```
cargo build --release
```

Готовые файлы: `target/release/SS14MidiStudio.exe` и `target/release/ss14midi.exe`.

Тесты: `cargo test --workspace`. Прогон на своих MIDI: задай папки в переменной `SS14MIDI_CORPUS` (через `;`) и запусти `cargo test --release -p ss14midi-core --test corpus -- --nocapture`.

## Устройство

- `crates/core` — ядро: чтение и запись MIDI, анализ, шаги оптимизации.
- `crates/cli` — консольная программа.
- `crates/app` — приложение на egui.
